Big Data Lakehouse Pipeline Architecture

INGESTION → HDFS PERSISTENCE → PARQUET COMPACTION → STREAMING INFERENCE
Step 1 • Ingestion
Apache Kafka Broker
High-frequency JSON sensor telemetry stream (T30, P30, Nc, Ps30, BPR) partitioned by Asset ID.
→
Step 2 • Lakehouse Storage
Hadoop HDFS Partitioning
Streaming micro-batches persisted with 3x replication in /lakehouse/year=YYYY/month=MM/day=DD/.
→
Step 3 • Batch Compaction
Snappy Parquet Compaction
Consolidates small streaming files into columnar Snappy Parquet for optimal query speeds and storage efficiency.
→
Step 4 • Feature Pipeline
73 Big Data Features
Sliding-window moving averages (5 & 15 cycles), volatility standard deviations, and rate-of-change deltas.
→
Step 5 • Real-time Inference
ML Classifier & Dispatch
Evaluates failure risk within 24h. Triggers work order dispatch when risk exceeds 70%.
